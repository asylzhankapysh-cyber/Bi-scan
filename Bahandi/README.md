# B-scan

Мобильная система заявок на списание с обязательным одобрением аккаунтов через Telegram.

## Что реализовано

- Регистрация отправителей и проверяющих с загрузкой удостоверения.
- Оба типа аккаунта получают статус `pending` и не имеют доступа до одобрения.
- Пароли хешируются сервером через `scrypt`; сессия хранится в защищённой `HttpOnly` cookie.
- Заявка и фотография документа отправляются в Telegram с кнопками «Одобрить» и «Отклонить».
- Telegram webhook проверяется секретным заголовком и ID управляющего чата.
- Одобрение атомарно генерирует уникальный ID формата `BH-000001`, QR-токен и цифровой пропуск.
- Отклонённый пользователь видит причину и может повторно подать заявку.
- Клиент не может активировать собственный аккаунт: решения выполняются только API и PostgreSQL.

## Запуск

1. Установите Node.js 20+ и PostgreSQL 15+.
2. Создайте базу `bscan` и примените схему:

```sh
psql -d bscan -f server/schema.sql
```

3. Скопируйте `.env.example` в `.env` и заполните значения.
4. Установите зависимости и запустите сервер:

```sh
npm install
npm start
```

Приложение откроется на `http://localhost:3000`.

## Telegram

Сначала перевыпустите ранее опубликованный токен через BotFather. Укажите новый токен только в `.env`.

Бот `@bscanrequests_bot` должен иметь возможность отправлять сообщения в управляющий чат. В `TELEGRAM_MANAGER_CHAT_ID` нужен реальный числовой ID этого чата, а не пример `123456789`.

После публикации сервера на HTTPS задайте `PUBLIC_BASE_URL` и выполните:

```sh
npm run telegram:setup
```

Telegram начнёт отправлять callback-события на `/api/telegram/webhook`.

## Email

Для писем об одобрении и отклонении заполните `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS` и `EMAIL_FROM`. Без SMTP решение сохранится, но письмо отправлено не будет.

## Важные ограничения

- Для Telegram webhook нужен публичный HTTPS-адрес; `localhost` Telegram вызвать не сможет.
- Документы сейчас хранятся в PostgreSQL как закрытые бинарные данные. Для большого production-развёртывания лучше перенести их в шифрованное объектное хранилище с ограниченным сроком хранения.
